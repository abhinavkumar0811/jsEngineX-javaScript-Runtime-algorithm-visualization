# 🌐 Global State & React Contexts

## Responsibility
Provides application-wide state management for execution playback, IDE layout configurations, active presets, and UI theme settings.

## Context Stores
- `TraceContext.jsx`: Current step index, playback state (playing/paused), playback speed, active trace step frame payload.
- `LayoutContext.jsx`: Panel visibility states, pane resize ratios, active visualizer tabs.
