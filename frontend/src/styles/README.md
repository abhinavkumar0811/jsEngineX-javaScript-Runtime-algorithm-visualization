# 💎 Styling & Design System

## Responsibility
Maintains the visual design system, glassmorphism UI tokens, CSS variables, typography, and dark theme specifications.

## Files
- `variables.css`: Palette hex codes, HSL color tokens, dark mode specs.
- `global.css`: CSS resets, custom scrollbars, typography rules (Inter/Outfit).
- `glassmorphism.css`: Backdrop-blur utility classes and translucent container styles.
