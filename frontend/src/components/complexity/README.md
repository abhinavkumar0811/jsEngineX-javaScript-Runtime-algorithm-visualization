# 📈 Time & Space Complexity Engine

## Responsibility
Renders algorithmic operation metrics, theoretical Big-O growth comparison charts, space breakdown, and mathematical step proofs.

## Components
- `OpCounter.jsx`: Real-time operation metrics and instruction counter badge.
- `GrowthChart.jsx`: Interactive Big-O growth curves ($O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$) using `Recharts`.
- `MathProof.jsx`: LaTeX mathematical derivation step proofs rendered via `KaTeX`.
