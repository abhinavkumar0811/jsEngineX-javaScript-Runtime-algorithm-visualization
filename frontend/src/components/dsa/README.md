# 📊 Data Structures & Algorithms (DSA) Visualizers

## Responsibility
Provides visual representations for linear and non-linear data structures, pointer movements, element swaps, and recursive call structures.

## Components
- `ArrayViz.jsx`: Flexbox/Canvas animated array bars & cards for sorting and array operations.
- `GraphViz.jsx`: Interactive tree and graph traversal visualizers (`@xyflow/react`).
- `RecursionTree.jsx`: Tree view of recursive function invocations synchronized with stack depth.
