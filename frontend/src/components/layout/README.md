# 📐 IDE Layout & Panel Management

## Responsibility
Manages the multi-panel IDE shell, dockable draggable panes (`react-resizable-panels`), top navbar, and execution playback controls.

## Components
- `IDELayout.jsx`: Main container arranging editor, visualizers, console, and complexity panels.
- `Header.jsx`: Navigation bar, preset selector, and theme switcher.
- `StepControls.jsx`: Step-by-step playback toolbar (Play, Pause, Step Next/Prev, Speed Slider, Scrub Bar).
