# 🎮 Express Request Controllers

## Responsibility
Contains request handling logic for Express routes, validating incoming HTTP payload data, invoking services, and returning formatted JSON responses.

## Key Controllers
- `presetController.js`: Serves preset algorithm list and pre-computed trace data.
- `snippetController.js`: Handles user code snippet persistence and shareable links.
- `traceController.js`: Handles heavy server-side trace calculation fallback endpoints.
